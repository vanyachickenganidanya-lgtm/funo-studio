# Официальный реестр библиотек Funo

Эти файлы предназначены для репозитория:

`https://github.com/vanyachickenganidanya-lgtm/funo_libsOFFICAL/tree/main`

## Как опубликовать первый пакет

1. Скопируйте `index.json` в корень репозитория.
2. Скопируйте папку `packages` в корень репозитория.
3. Закоммитьте изменения в ветку `main`.
4. В Funo Studio откройте «Библиотеки» и нажмите «Обновить».

Структура:

```text
funo_libsOFFICAL/
├── index.json
└── packages/
    └── hello/
        └── hello.funpkg
```

## Проверка

Для каждого файла пакета вычислите SHA-256:

```bash
sha256sum packages/hello/hello.funpkg
```

Запишите полученное значение в поле `sha256`. Если содержимое пакета поменялось, увеличьте версию и пересчитайте SHA-256.

> `verified: true` само по себе не делает пакет безопасным. Funo Studio также требует HTTPS и совпадение SHA-256. В следующей версии реестра можно добавить цифровые подписи.
